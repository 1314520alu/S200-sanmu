## 手工做法（专业版，备用）

### 1. 先建封装库（必须有焊盘）

1. **文件 → 新建 → 封装**
2. **文件 → 导入 → DXF**  
   选：`export/lceda_x25_footprint/CUAV_X25_MEGA_TRUE_TOP.dxf`  
   单位 **mm**，比例 **1**  
   外框/脚 → 顶层丝印（参考线）
3. 放置 **4 个多层焊盘**（安装孔），编号必须与原理图引脚一致，例如 `1~4`：

| 焊盘号 | X (mm) | Y (mm) | 孔径 | 建议焊盘外径 |
|--------|--------|--------|------|--------------|
| 1 | -25.50 | -26.75 | 3.2 | 6.0 |
| 2 | 25.50 | -26.75 | 3.2 | 6.0 |
| 3 | 25.50 | 26.75 | 3.2 | 6.0 |
| 4 | -25.50 | 26.75 | 3.2 | 6.0 |

   原点 = 封装中心；孔距 51×53.5。  
   也可用 **文件 → 导入 → 焊盘坐标文件**（先下官方模板，填入 `CUAV_X25_MEGA_pads.csv` 数值）。
4. 非金属化安装孔：焊盘属性里「金属化 = 否」，或用圆形挖槽。
5. 保存封装，名称例如：`CUAV_X25_MEGA`

### 2. 绑定 3D（可选但推荐）

1. **文件 → 新建 → 3D模型** → 导入 `export/lceda_x25/CUAV_X25_MEGA.obj`
2. 在封装属性里绑定该 3D，用「3D模型管理器」对齐

### 3. 建器件 = 符号 + 封装

1. **文件 → 新建 → 器件**
2. 绑定：
   - **符号**：你原理图里用的 X25 符号（引脚号 = 1,2,3,4…）
   - **封装**：上一步的 `CUAV_X25_MEGA`
3. 保存器件

### 4. 原理图里换成「器件」并再转 PCB

1. 打开原理图 → **设计 → 封装管理器**（或 Alt+F）
2. 找到 X25：若「封装」为空或报错 → **指定/替换** 为刚建的封装  
   - 引脚编号必须与焊盘编号一一对应  
   - 引脚数量不能多于焊盘数量
3. 保存后：**设计 → 原理图转PCB / 更新PCB**
4. PCB 上应出现 X25 封装；若在外面，用「按电路排布」或手动拖入板框

## 常见踩坑

| 现象 | 原因 | 处理 |
|------|------|------|
| 转 PCB 直接报错 | 封装未指定 / 引脚对不上 | 封装管理器逐项修 |
| 转成功但没有 X25 | 该元件被跳过或只是文本/图块 | 换成带封装的**器件** |
| 只有 DXF 线没有焊盘 | DXF 不会自动变成封装 | 必须手动放焊盘并保存为封装库 |
| 3D 有了但 PCB 没有 | 3D ≠ 封装 | 3D 只是外观，不能代替焊盘封装 |
