# S200 LCEDA MCP v1.2 优化

日期：2026-09-20  
状态：已批准（方案 3）

## 目标

1. **Agent 效率**：压缩 JSON、附耗时、`diagnose` 一次出 Hub+登录+工程结论  
2. **画布直调**：经 Hub HTTP MCP（`:7900`）调 `eda_context` / `api_invoke`，跳过官方多轮 index→search

## 新增 / 变更

| 工具 | 说明 |
|------|------|
| `diagnose` | Hub + cookie + `project_status` 摘要，默认首选诊断入口 |
| `eda_snapshot` | 精简当前工程/页上下文（经 Hub HTTP） |
| `eda_invoke` | 直接 `apiFullName` + args 调画布 API（经 Hub HTTP） |
| 全部工具 | 返回改为紧凑 JSON，带 `ms` |

## 非目标

- 不替代选型确认流（`component_select` 仍用官方）  
- 不实现完整 API 索引检索（已知 API 名时用 `eda_invoke`）

## 成功标准

- `diagnose` < 3s（本地）  
- Bridge 已连时 `eda_snapshot` < 5s  
- Agent 修 X25 仍优先本地工具，不依赖 Bridge
